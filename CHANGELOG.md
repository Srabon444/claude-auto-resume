# Changelog

## 0.2.0

- New choice when starting a timer: send what is in the chat box (your prompt and attachments) instead of `continue`.

## 0.1.0

First release.

- Set a timer for a chat. When it ends, `continue` and Enter are sent in that chat.
- Every chat tab has its own timer, so several chats can run at once.
- Time can be typed as `5h 3m`, `5:03`, `90m`, `1.5h` or `45` (minutes), and the box shows when the timer will end.
- Works on Windows, macOS and Linux (X11 and Wayland).
